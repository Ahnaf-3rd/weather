This is a simple weather app using a weather API. To use it, go to the link and search the city you are looking for in the search bar. The default is set to Sylhet since
that's the city I am from. <br>
This is an web application that will show you the detailed condition of the weather of the particular city you are looking for. The information includes, humidity, wind speed, UV index, temperature, relative humidity and the forecast for the next five days. The units used are both in SI and British Imperial systems.
